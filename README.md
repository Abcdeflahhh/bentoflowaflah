# 🍱 BentoFlow — AI-Powered Bento Grid Portfolio Builder

> **A modern, aesthetic, and dynamic Bento Grid portfolio builder crafted with Next.js 15, React 19, TypeScript, Tailwind CSS, Framer Motion, and AI Copilot.**

Designed and developed by a **Semester 5 Computer Science (Teknik Informatika) student** exploring the intersection of **Design Engineering**, **Full-Stack Development**, and **AI-augmented ("vibe") coding**.

---

## ✨ Key Features

- **🍱 Bento Grid Architecture**: Flexible, modular grid supporting `1x1`, `2x1`, `1x2`, and `2x2` card layouts.
- **🔄 Drag-and-Drop Reordering**: Smooth real-time spatial sorting powered by `@dnd-kit/core` and `@dnd-kit/sortable`.
- **🎨 5 Curated Design Themes**:
  - `Dark Minimal` (Vercel / Apple clean aesthetic)
  - `Midnight Violet` (Linear / Raycast obsidian glow)
  - `Cyber Neon` (High-contrast tech cyberpunk)
  - `Warm Amber` (Warm editorial retro tones)
  - `Clean Light` (Airy high-contrast light mode)
- **⚡ AI Copilot Bar**: Intelligent generative prompt bar that analyzes user persona (e.g. *Backend Go engineer* or *Mobile Flutter builder*) and automatically adapts the color scheme, headline, bio, and recommended bento cards.
- **👁️ Public Preview Mode**: Instant one-click toggle between interactive editor mode and clean public showcase view.
- **🔗 Share & Copy**: Instant clipboard sharing for recruiters and collaborators.

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/your-username/bentoflow.git
cd bentoflow
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
